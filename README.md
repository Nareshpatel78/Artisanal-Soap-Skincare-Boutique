# Artisanal Handmade Cold-process Soap And Skincare Boutique

A luxury navy-blue and royal-gold, 11-page responsive student e-commerce website built with HTML, CSS and vanilla JavaScript.

## Pages
1. `index.html` — Home
2. `shop.html` — Shop with search, category, price and rating filters
3. `product.html` — Product details (opens with `?id=product-id`)
4. `cart.html` — Shopping cart with quantity controls and remove
5. `checkout.html` — Demo checkout form
6. `login.html` — Demo account creation/login
7. `order-success.html` — Demo order confirmation
8. `about.html` — Our story
9. `contact.html` — Demo contact form
10. `wishlist.html` — Saved products
11. `faq.html` — Expand/collapse FAQs

## Run
Extract the ZIP and open `Artisanal_Boutique_Exact_Reference/index.html` in Chrome, Edge or Firefox. No server or installation is required.

## Interactive features
- Product search, sorting and category/price/rating filters
- Add to cart, quantity updates and remove
- Wishlist toggle and counters
- Product detail pages
- Demo account and checkout flows
- FAQ expand/collapse
- Responsive desktop and mobile layouts
- Browser localStorage for demo cart, wishlist and account state

## Product photography
The `images/` folder contains 20 product photographs from the supplied product-image PDF. They are mapped to the closest matching product names from the supplied listing. A few matches are visual approximations where the PDF did not provide a product caption.

## Important demo note
This is a front-end academic demo. Payment, login, contact submissions, inventory and order delivery are not connected to a real backend. Do not enter real passwords or payment information.
